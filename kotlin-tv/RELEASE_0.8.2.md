# Kotlin 0.8.2：TV 界面与遥控器交互优化

最低 Android 8.0 / API 26，versionCode 10。沿用 0.8.1 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 界面与交互

- 应用名称统一为 `红果TV`。
- 重绘 TV 图标，移除深色全尺寸背景，适配深色电视界面。
- 导航栏移动焦点即可切换首页、搜索、排行榜、收藏、最近观看和设置。
- 进入搜索页自动聚焦输入框并唤起系统输入法。
- 搜索页的短剧/漫剧类型按钮移动焦点即可切换；已有关键词时自动刷新第 1 页结果。

## 已包含的搜索修复

- App 搜索接口返回 HTTP 200 空响应时，短剧和漫剧搜索回退到官网 SSR 搜索。
- 空响应不再触发 `End of input at character 0`。
- 合法的空搜索结果不会误触发回退。

## 验证

源码默认版本为 `0.8.2` / `versionCode 10`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
