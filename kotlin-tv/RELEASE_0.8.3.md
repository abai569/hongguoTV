# Kotlin 0.8.3：合并搜索与固定手机推送

最低 Android 8.0 / API 26，versionCode 11。沿用 0.8.2 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索体验

- 搜索页改为一个统一“搜索”按钮，短剧和漫剧结果合并并按剧集 ID 去重。
- 搜索历史直接显示在输入框下方，选择历史只填入关键词，不自动搜索。
- 手机推送只填入电视搜索框，用户仍通过遥控器确认“搜索”后执行。

## 手机推送

- 固定监听端口 `8787`，二维码地址为 `http://电视IP:8787/`。
- 手机页面只包含剧名输入和提交按钮。
- 支持连续推送多个剧名，不再使用随机 token、一次性提交或 5 分钟过期。
- 手机服务在离开搜索页面或关闭应用时停止。

## 验证

源码默认版本为 `0.8.3` / `versionCode 11`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
