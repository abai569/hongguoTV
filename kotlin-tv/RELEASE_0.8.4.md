# Kotlin 0.8.4：搜索页体验修正

最低 Android 8.0 / API 26，versionCode 12。沿用 0.8.3 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 修正内容

- 搜索输入框提示统一为“请输入剧名或关键词”。
- 搜索页移除漫剧/短剧切换按钮；搜索已合并两类结果，首页继续保留内容类型切换。
- 进入搜索页不再自动弹出输入法，按确认键或回车键才打开。
- 手机推送二维码缩小白色留白，右侧面板与输入框顶部对齐并居中显示文本。
- 保留 0.8.3 的搜索合并、固定 8787 手机推送和搜索历史内嵌。

## 修复回归

- 搜索历史按钮与搜索按钮不再重复挂载到同一父布局。

## 验证

源码默认版本为 `0.8.4` / `versionCode 12`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
