# Kotlin 0.8.5：电视搜索页重做

最低 Android 8.0 / API 26，versionCode 13。沿用 0.8.4 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索页

- 左侧电视端软键盘：清空、删除、搜索，以及 A-Z、0-9 按键，无需系统输入法。
- 顶部“关键字”实时跟随键盘输入。
- 右侧“历史”和“热门推荐”标签，点击填入并搜索。
- 保留短剧与漫剧合并搜索，历史记录本机保存。

## 手机推送

- 改为弹窗显示二维码、访问地址和说明。
- 固定 8787 端口，可连续推送剧名，离开或关闭应用时停止。

## 验证

源码默认版本为 `0.8.5` / `versionCode 13`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
