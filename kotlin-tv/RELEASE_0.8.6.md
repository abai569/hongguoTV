# Kotlin 0.8.6：搜索页标签与联想优化

最低 Android 8.0 / API 26，versionCode 14。沿用 0.8.5 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索页

- 历史、热门、建议统一为不截断的换行芯片：内容宽度、放不下自动换行，超长标题最多两行完整显示。
- 右栏可滚动，内容不再被裁掉。
- 键盘功能行新增“推送”，点击打开手机推送二维码弹窗；移除右栏单独的推送按钮。
- 焦点可从键盘移动到右栏芯片。

## 输入即联想

- 键入后约 250ms 防抖请求搜索，右侧“热门推荐”切换为“建议”。
- 输入为空时显示“历史 + 热门推荐”。
- 支持拼音首字母联想与搜索（官网搜索支持，例如 `wytl` 命中《万妖图录传》）。
- 点击建议或按“搜索”执行完整搜索。

## 手机推送

- 二维码使用常规样式，显示访问地址与说明。
- 固定 8787 端口，可连续推送剧名，离开或关闭应用时停止。

## 验证

源码默认版本为 `0.8.6` / `versionCode 14`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
