# Kotlin 0.8.7：搜索页与图标优化

最低 Android 8.0 / API 26，versionCode 15。沿用 0.8.6 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 图标

- 放大应用图标，珊瑚色方块与播放符号占满画布，电视桌面更醒目。

## 搜索页

- 右侧栏底部显示“下一段好故事，从这里开始”和“浏览片库，选择你想看的剧”。
- 删除底部“输入关键词，用遥控器确认搜索”提示。
- 保留历史、热门、建议的不截断换行芯片与输入即联想。
- 遥控器可从软键盘向右移动到右栏标签。

## 手机推送

- 键盘功能行“推送”键打开二维码弹窗；右栏不再有独立推送按钮。

## 验证

源码默认版本为 `0.8.7` / `versionCode 15`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
