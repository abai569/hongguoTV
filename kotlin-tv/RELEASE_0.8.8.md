# Kotlin 0.8.8：搜索结果整屏显示

最低 Android 8.0 / API 26，versionCode 16。沿用 0.8.7 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索

- 搜索后在独立结果页整屏显示结果卡片，不再挤在软键盘下方的小区域。
- 结果页顶部显示当前关键词，并提供“修改关键词”返回键盘继续编辑。
- 无关键词时仍显示软键盘、历史、热门与建议。

## 验证

源码默认版本为 `0.8.8` / `versionCode 16`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
