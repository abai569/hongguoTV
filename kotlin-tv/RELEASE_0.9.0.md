# Kotlin 0.9.0：焦点与手机推送优化

最低 Android 8.0 / API 26，versionCode 18。沿用 0.8.9 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 交互

- 打开应用或切换标签时，焦点停在顶部导航栏对应标签上，不再直接落到页面内容。
- 从导航栏按向下键进入内容区。

## 手机推送

- 修复手机推送页：清空按钮改为链接，提交可正常发送到电视。
- 放宽同源来源校验，兼容浏览器提交。
- 支持连续推送剧名。

## 文案

- 删除各页面“下一段好故事，从这里开始”“浏览片库，选择你想看的剧”说明文字。

## 验证

源码默认版本为 `0.9.0` / `versionCode 18`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
