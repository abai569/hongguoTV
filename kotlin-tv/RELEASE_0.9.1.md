# Kotlin 0.9.1：首页预览与刷新按钮优化

最低 Android 8.0 / API 26，versionCode 19。沿用 0.9.0 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 首页

- 未选中剧集时收起初见预览区，不再留下空白“遮罩”；选中卡片时显示剧名与状态。
- “刷新热门”从页面底部移到“热门发现”分区标题右侧，改为紧凑按钮，不再占满整行。

## 验证

源码默认版本为 `0.9.1` / `versionCode 19`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
