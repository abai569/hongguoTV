# Kotlin 0.9.2：搜索输入框与手机推送修复

最低 Android 8.0 / API 26，versionCode 20。沿用 0.9.1 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索页

- “关键词”后恢复可编辑输入框，与电视软键盘双向同步；选中后可调出系统输入法编辑。
- 进入搜索页焦点停在顶部导航栏，不再自动跳到键盘“清空”键；按向下键进入输入框，再向下进入键盘。

## 手机推送

- 恢复二维码完整静默区，避免裁掉白边导致扫不出来。
- 监听端口启用地址复用，避免重复打开时端口占用失败。
- 支持 GET 提交兜底（`/submit?query=`），清空改为链接 `/clear`；放宽同源校验。

## 验证

源码默认版本为 `0.9.2` / `versionCode 20`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
