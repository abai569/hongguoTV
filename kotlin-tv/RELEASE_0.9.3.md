# Kotlin 0.9.3：手机推送与覆盖安装修复

最低 Android 8.0 / API 26，versionCode 21。沿用 0.9.2 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 手机推送

- 打开“手机推送”和“手机备份与恢复”时保持电视屏幕常亮。
- 修复电视进入屏保触发 `onStop`、关闭推送服务，导致手机提交出现 `ERR_CONNECTION_REFUSED` 的问题。

## 覆盖安装

- CI 缓存 debug 签名密钥，使各版本 APK 使用同一签名，后续版本可直接覆盖安装。
- 本版与电视上已安装的旧签名版本不同，首次仍需卸载一次；此后可覆盖安装。

## 搜索页

- 搜索页“关键词：”标签已隐藏，仅保留输入框。

## 验证

源码默认版本为 `0.9.3` / `versionCode 21`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK 到 GitHub Release。
