# Kotlin 0.9.5：搜索页比例调整

最低 Android 8.0 / API 26，versionCode 23。沿用 0.9.4 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索页

- 软键盘缩小：键高 50→42dp、字号 20→18f，数字两行合并为一行，整体更矮。
- 左右栏改为等宽（左栏权重 1.2→1.0），右侧区域更宽。
- 右侧标签字号 15→18f，内边距加大；“历史”“热门推荐”标题 20→22f。
- 热门推荐数量 8→15。

## 验证

源码默认版本为 `0.9.5` / `versionCode 23`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK、`update.json` 和 `SHA256SUMS` 到 GitHub Release。
