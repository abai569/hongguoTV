# Kotlin 0.9.6：搜索键盘微调

最低 Android 8.0 / API 26，versionCode 24。沿用 0.9.5 发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索页

- 键盘只收窄宽度，不降低高度：键高、字号恢复原样，数字恢复两行 0-4 / 5-9。
- 键盘左栏权重 1.0→0.8，右侧区域更宽。
- 功能行顺序改为「搜索 清空 删除 推送」，“搜索”在最左第一个。

## 验证

源码默认版本为 `0.9.6` / `versionCode 24`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK、`update.json` 和 `SHA256SUMS` 到 GitHub Release。
