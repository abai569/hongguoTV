# Kotlin 1.0.0：搜索与推送修复

最低 Android 8.0 / API 26，versionCode 28。沿用固定发布签名，可直接覆盖安装并保留本机收藏、观看记录和设置。

## 搜索

- 搜索结果页返回后焦点自动移到「清空」按钮，键盘可正常操作。
- 热门推荐显示全部 15 个，不再限制 8 个。
- 词条按左键逐键向左移动，不再跳回搜索按钮。

## 推送

- 推送服务持续运行直到关闭软件，不再随弹窗关闭而中断。
- 放宽 Host 校验（只比较 IP），手机提交不再报 404。

## 首页

- 热门发现 3 行 18 个，支持多行 shelf 布局。

## 验证

源码默认版本为 `1.0.0` / `versionCode 28`。CI 执行核心测试、Android lint 和 Debug APK 构建，并在标签构建完成后上传 APK、`update.json` 和 `SHA256SUMS` 到 GitHub Release。
